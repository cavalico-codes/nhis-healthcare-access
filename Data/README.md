# Data (not included)

Download these two files from the National Center for Health Statistics and place them in this folder **without unzipping**:

| File | Source |
|---|---|
| `adult24csv.zip` (2024 Sample Adult file, CSV) | https://ftp.cdc.gov/pub/Health_Statistics/NCHS/Datasets/NHIS/2024/adult24csv.zip |
| `adultinc24csv.zip` (2024 imputed income file, CSV) | https://ftp.cdc.gov/pub/Health_Statistics/NCHS/Datasets/NHIS/2024/adultinc24csv.zip |

The 2024 NHIS documentation page, which holds the Sample Adult codebook and survey description, is at https://www.cdc.gov/nchs/nhis/documentation/2024-nhis.html.
The codebook (`adult-codebook.pdf`) is optional; the code does not read it.

The zip files are ignored by git (see `.gitignore`).
