# Social determinants and access to health care among U.S. adults (NHIS 2024)

Analysis code for the manuscript *Social determinants and access to health care among U.S. adults: a cross-sectional analysis of the 2024 National Health Interview Survey* (Olson CVL).

Every number, table and figure in the manuscript is generated by `Codes/02_corrected_analysis.ipynb` from the public-use 2024 NHIS Sample Adult file. The work started as a master's capstone (HTM692, National University); notebook 01 replicates the original SAS analysis in Python, and notebook 02 contains the corrected analysis used in the manuscript.

## Repository layout

```
Codes/
  01_replication.ipynb          Python re-run of the capstone's SAS models; documents the outcome-direction error
  02_corrected_analysis.ipynb   Corrected analysis behind the manuscript (7 outcomes, sensitivity analyses, figures)
  nhis_survey.py                Survey-weighted logistic regression (Taylor linearization), recodes, marginal standardization, MI pooling
  plots.py                      Figure helpers
  thesis_tables.py, validate_port.py   Only used by notebook 01 (compare against the printed thesis tables)
  results/                      CSV/JSON outputs written by notebook 02 (and 01)
  figures/                      Figures written by the notebooks
Data/                           Put the NHIS files here (not included; see Data/README.md)
requirements.txt                Package versions used to produce the results
```

## How to reproduce

1. Download the two public-use files listed in `Data/README.md` into `Data/` (do not unzip them).
2. Create an environment and install the requirements (developed on Python 3.10; also run on 3.13 with identical results):
   ```
   pip install -r requirements.txt
   ```
3. Open `Codes/02_corrected_analysis.ipynb` and run all cells (about 1 minute). The notebook rewrites `Codes/results/` and `Codes/figures/`.
   From the command line: `cd Codes && jupyter nbconvert --to notebook --execute --inplace 02_corrected_analysis.ipynb`.

Notebook 01 additionally needs the capstone `.docx` placed in the repository root (it reads the printed SAS results from it). The thesis file is not distributed here, so notebook 01 is for reference; its saved outputs are included.

## Method summary

- Design: NHIS 2024 Sample Adult file, n = 32,629; weight `WTFA_A`, strata `PSTRAT`, PSUs `PPSU`; 610 degrees of freedom.
- Models: one survey-weighted logistic regression per outcome (event = 1 = access problem) with ten mutually adjusted predictors; Taylor-linearized variances with t-based confidence intervals.
- Extras: model-standardized adjusted prevalences and risk differences (delta method), Benjamini-Hochberg q-values, and four sensitivity analyses (insurance status as covariate, ten NCHS income imputations pooled by Rubin's rules, unweighted models, VIFs).
- The estimator was checked against SAS `PROC SURVEYLOGISTIC` output from the original analysis (odds ratios and confidence limits agree within 0.002 for same-specification models; see notebook 01).
